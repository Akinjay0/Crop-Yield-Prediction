# Crop-Yield-Prediction (Data Oracles Group Project)
This project aims at predicting crop yield using environmental and agricultural factors such as rainfall, temperature and pesticide usage.

## Objective
- To perform EDA
- To identify key predictive features
- To build a regression model and deploy a web app for yeild prediction

## Technologies
- Python (pandas, scikit-learn, seaborn, matplotlib,)
- Streamlit
- Numpy
- Pickle
